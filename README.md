New CameraToolKit
The current version includes the following features:

Autopilot. Press Num 0 to start recording a route, then press Num 0 again to finish recording. Return to the starting point and press F9 - the recorded route will be played back. To adjust playback accuracy, edit the sliders in the "AUTO" tab. The autopilot mode currently has some issues and occasionally deviates from the route, and the car itself does not react to obstacles such as traffic, so for now this feature only performs well over short distances and with minimal risk of deviation (e.g., bumps). A visible route curve has also been added to this mode to make it easier to orient yourself with the start and end points. Unfortunately, it displays far outside the map rather than above the road, so this feature still needs some tweaking. Press F8 to toggle the curve on and off.
Camera shake effect (handheld camera simulation). This feature is located a bit lower in the "CAMERA" tab. The shake activates after enabling any camera. Edit the frequency and amplitude of the effect to achieve the desired result.
Composition grid. Still in the "CAMERA" tab, you can now enable a composition grid for framing your shots. As with the shake effect, you can fully edit the sliders to build the grid you need.
Two new light sources in the "LIGHTS" section: flashlight and string lights!
For the flashlight - activate the source in free camera mode, then switch to any other camera, and you can now move around together with the glowing circle. By the way, this light source can be edited however you like and even duplicated.
Garland - a set of small bulbs of various colors that can be duplicated up to 64 pieces, with adjustable spacing intervals, arc-shaped or hanging arrangements, and a flickering effect. 
Speaking of flickering: if you're into cinematics but find cutting frames to create this effect quite painful, it's no longer a problem - every light source now has a "Flicker" function, allowing you to choose the desired flickering and fading effect and fine-tune it afterwards.
The CameraToolKit window can now be resized for ease of use. Just grab the edge of the opened window and drag.

That's all that has been implemented in this updated version of the tool so far. Not everything works perfectly or is fully polished, so additional refinement will be needed.
